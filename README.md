# Legal-Ease - AI Powered Legal Document Generator

An AI-powered platform that helps users generate legal documents easily.

## Features
- Generate legal documents using AI
- Backend API with FastAPI
- Interactive Frontend with Streamlit

## Tech Stack
- Backend: Python, FastAPI
- Frontend: Streamlit
- AI: Google Gemini

## How to Run
1. Clone the repo
2. pip install -r requirements.txt
3. Run backend: uvicorn backend.main:app --reload
4. Run frontend: streamlit run frontend/app.py
